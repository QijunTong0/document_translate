論文のtex source(zip)形式を入力として，それを和訳して日本語の論文を生成するスクリプトを作成したいです．要件は以下です

1. 和訳エンジンはユーザーが契約しているclaude codeまたはcodexの非対話モードを利用する
2. 日本語tex環境はdockerを使い，ユーザー環境での環境構築を軽減する
3. 本文は与えたtex sourceのtexファイルを訳す形にする
4. 図などで既に英文が埋め込まれている場合はその図をそのまま使い，訳さなくてよい．
5. デフォルトのプロンプトは用意しておく．論文の和訳というタスクを明確に規定する．オプションでプロンプトを与えられるようにしておく



1,2,3,4についてスクリプトを作成してください

5について，他にプロンプトに盛り込んでおいたほうが良い内容を考えて欲しいです．特にAIは無理に専門用語を訳して不自然になったり，文脈を無視した訳文を生成しがちです．また論文に適した文体や言い回しの和訳が生成されるように努めてください．
